## Priority Issues

### [P1] The menu is visually modal but not behaviorally accessible

`#Menu-cerrar` remains a clickable span without Escape handling, focus return, focus containment, or explicit expanded state. Replace it with a labeled button and manage focus and ARIA state.

### [P1] Motion and autoplay media ignore user preferences

Videos autoplay and loop, while scale/fade transitions have no `prefers-reduced-motion` path. Add reduced-motion rules and pause or replace autoplay media for constrained-motion/data contexts.

### [P1] Desktop viewport containment can clip work

At desktop sizes `.Main` uses `height: 100vh` and `overflow: hidden`, forcing seven rows into the viewport. Test 100%, 125%, and 200% zoom and long titles; prefer controlled scrolling over unconditional clipping.

### [P2] Project relevance is still undersold

Services were added, but not year, role, outcome, or short descriptor. Add one restrained metadata line without weakening title/image hierarchy.

### [P2] Failure states remain invisible

A JavaScript failure leaves an empty list; media failures and future empty filters have no explanation. Add progressive fallback content, media fallback styling, and validate invalid detail-page ids.
